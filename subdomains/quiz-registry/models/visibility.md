# Visibility

Value object on [`QuizList`](quiz-list.md). Who can find the list, view it and start a session from
it.

- `Public`: anyone.
- `Unlisted`: anyone with the link.
- `Private`: only the owner.

Whether a quiz may be in the list is a separate question, answered by the quiz's
[`InclusionPolicy`](inclusion-policy.md).
