# CreativeCommons

Value object. A Creative Commons license or dedication.

- `Zero`: CC0 1.0, a dedication to the public domain. No version, only one exists.
- `By`, `BySa`, `ByNc`, `ByNcSa`, `ByNd`, `ByNcNd`: the six licenses, each with its version.

Only version 4.0 is modeled. Users publishing their own quizzes pick the current version. Older
versions are added when an import needs one. Ported (jurisdiction) versions are not modeled.
